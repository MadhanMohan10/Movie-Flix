# Movie-Flix Frontend

React + Bootstrap frontend for the Movie-Flix backend.

## Structure

- `src/api` for backend calls
- `src/components` for shared UI
- `src/context` for auth state
- `src/hooks` for reusable hooks
- `src/pages` for routed screens
- `src/routes` for app routing

## Run

```bash
npm install
npm run dev
```
